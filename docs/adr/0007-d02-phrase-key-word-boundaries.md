# 0007. D02 — фраза-ключ с границей слова с обеих сторон

## Контекст

План (исходная формулировка spec.md §3) описывал фразу-ключ (`kind=phrase`)
как совпадение «как есть» — буквальная подстрока в тексте, без явного условия
про границы слова по краям фразы.

## Решение

Сборка потребовала: фраза компилируется как `\b<escaped>\b` — с границей слова
и в начале, и в конце. spec.md §3 приведён в соответствие фактическому
поведению задним числом.

## Почему

Рассмотрен и отклонён вариант «как есть», без границ с обеих сторон:
фраза находилась бы слитно с соседними буквами (например, часть более
длинного слова или соединённого без пробела текста), что нарушало бы общий
для всей системы принцип «совпадение по границе слова», уже принятый для
обычных ключей (R17), и делало бы поведение фразы непоследовательным
относительно остального матчера.

## Последствия

Точная фраза никогда не совпадёт, если она — часть слова без пробелов вокруг
(даже если по смыслу текста это то же самое сочетание). Формулировка
spec.md §3 была скорректирована постфактум, а не предсказана планом заранее —
любой будущий читатель спеки должен ориентироваться на актуальную версию, а не
на исходную формулировку, зафиксированную до этой правки.
