# Эталон

На что это должно быть похоже. Собрано со слов пользователя — не выдумано.

Пользователь подтвердил (брифинг, 2026-08-28): «Хватит текста брифа» — эталоном для
доводки служат точные формулировки и структура меню, уже продиктованные в брифе.
Отдельного бота-образца или стороннего интерфейса не называлось.

## Тексты и тон

- Шаблон подписи источника, дословно из брифа §3.3:
  ```
  🔑 ремонт, срочно
  👤 Иван П. · @ivan_p · id 123456789
  💬 Чат: «Ремонт СПб» · ссылка на оригинал
  🕐 27.08.2026 14:32
  ```
- Сообщение о падении сессии, §6: «⚠️ Сессия отвалилась, запусти вход заново»
- Диалог о догоне при снятии паузы, §4.5: «⏸ Пауза длилась 3 ч 20 мин. Догнать пропущенное? [Да] [Нет]»
- Ответы кнопки «🧪 Проверить», §4.3: «✅ сработало по: ремонт, срочно» /
  «❌ не сработало» / «⛔ заблокировано минус-словом: вакансия»
- Итог мастера настройки, §5: «userbot подключен как Иван, бот @xxx жив, доступ у ID 123»
- Ответ на доступ без прав, §5: «Доступ запрещён»

## Структура меню

- «➕ Добавить чат» → три способа: «📋 Из моих чатов» (постранично по 8, с поиском),
  «↩️ Переслать сообщение», «⌨️ Ввести вручную» (§4.1, повторяется в §4.2 плюс «💾 Избранное»)
- У каждого элемента списка — своя кнопка действия: «❌ удалить», переключатель «пауза»
- Эмодзи как смысловые метки разделов, не украшение: 🔑 ключи, 👤 автор, 💬 чат, 🕐 время,
  ⏸/▶️ статус мониторинга, 📊 статистика

## Чего быть не должно

- Ничего не редактируется руками через конфиги — только кнопками и текстовым вводом в боте (§4).
