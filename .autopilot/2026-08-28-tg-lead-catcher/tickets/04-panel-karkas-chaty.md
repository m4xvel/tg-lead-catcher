# 04 — Панель: каркас, доступ, источники и приёмники

**Требования:** R02, R03, R07, R38, R39, R40, R40.1, R41, R42, R48, R59, R79i

**Волна:** 3
**Status:** ready

## Что должно заработать

aiogram-бот (токен от @BotFather), только панель — сам никогда не форвардит.
Каждое входящее действие сверяет `from_user.id` с `OWNER_ID` из `.env`; чужому —
«Доступ запрещён» и запись попытки в лог, без исключений и без дальнейшей
обработки апдейта. Дальше — управление источниками и приёмниками: кнопка
«➕ Добавить чат» с тремя способами («📋 Из моих чатов» через `userbot.list_dialogs()`
постранично по 8 с поиском по названию; «↩️ Переслать сообщение» — берёт chat_id
из форварда; «⌨️ Ввести вручную» — @username/ссылка/числовой id, с понятной
ошибкой, если чат не резолвится). У приёмников — те же три способа плюс кнопка
«💾 Избранное» одним нажатием, оно же приёмник по умолчанию при первом запуске
(если список приёмников пуст). Списки — постраничные, у каждого элемента ❌
(удаляет сразу, без подтверждающего диалога) и, только у источников, переключатель
«пауза» (вызывает `userbot.catch_up` при снятии — без вопроса о догоне, тикет 02
уже это гарантирует). Глобальный тумблер мониторинга ⏸/▶️ — отдельная кнопка
верхнего уровня, отдельная от паузы конкретного источника.

## Из брифа, дословно

> «Bot API-бот (aiogram 3, токен от @BotFather) — только панель управления. Пересылку не делает: Bot API физически не может форвардить из чата, где бота нет.»
> «Списки целевых чатов (приёмников), чатов для поиска (источников)... пользователь должен уметь добавлять и удалять сам, через UI, а не через код.»
> «Кнопка «➕ Добавить чат» даёт три способа: «📋 Из моих чатов» (основной)... «↩️ Переслать сообщение»... «⌨️ Ввести вручную»...»
> «Список источников — постранично, у каждого ❌ удалить и переключатель «пауза» (временно отключить, не удаляя).»
> «Те же три способа плюс кнопка «💾 Избранное» (Saved Messages) одним нажатием — она же приёмник по умолчанию при первом запуске.»
> «Тумблер мониторинга ⏸/▶️ — остановить, не выключая программу.»
> «Доступ к панели — только у Telegram ID владельца, записывается в .env на этапе мастера. Любому другому бот отвечает «Доступ запрещён» и логирует попытку.»

## Критерии приёмки

- [ ] Апдейт от id, не равного `OWNER_ID`, получает «Доступ запрещён» и попадает в лог попыток; ни одно действие не выполняется
- [ ] «Из моих чатов» показывает список постранично по 8, поиск по названию сужает список
- [ ] Пересланное в бота сообщение добавляет соответствующий чат как кандидат-источник/приёмник
- [ ] Ручной ввод принимает `@username`, `t.me/...` и числовой `chat_id`; нерезолвящийся ввод — понятная ошибка, ничего не добавляется
- [ ] «💾 Избранное» добавляется как приёмник в одно нажатие; при пустом списке приёмников оно уже есть по умолчанию сразу после первого запуска
- [ ] ❌ у любого элемента списка удаляет его немедленно, без второго подтверждающего шага
- [ ] Переключатель «пауза» у источника отключает его без удаления из списка; повторное включение вызывает `userbot.catch_up` для этого чата
- [ ] Глобальный тумблер ⏸/▶️ виден и переключается независимо от пауз отдельных источников
- [ ] Все тексты и кнопки — на русском
