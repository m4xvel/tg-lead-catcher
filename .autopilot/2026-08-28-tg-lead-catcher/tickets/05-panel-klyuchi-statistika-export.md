# 05 — Панель: ключевые слова, проверка, статус, статистика, история, экспорт

**Требования:** R04, R44, R45, R46, R47, R49, R50, R51, R52, R53, R55, R79i
**Blocked by:** 04
**Зона:** `panel/keywords.py`, `panel/stats.py`, `panel/export.py`
**Волна:** 4
**Status:** ready

## Что должно заработать

Раздел ключевых слов и отдельный раздел минус-слов с одинаковым построчным
вводом: пришёл текст в N строк — добавились новые ключи нужного типа
(слово/фраза/regex по синтаксису из тикета 01), дубли отсекаются молча.
У каждого элемента — кнопка удаления, без подтверждения (как и везде в этой
панели). Кнопка «🧪 Проверить» прогоняет введённый текст через `matcher` (не
сохраняя ничего) и отвечает одним из трёх точных текстов из брифа. Экран
статуса — работает ли мониторинг, число источников/ключей, что в очереди
доставки, время последнего срабатывания. Статистика за 7 и 30 дней — по
сработкам, ключам, чатам; «Топ мусорных ключей» — те же данные, отсортированные
по количеству. История — последние 50 срабатываний со ссылками на оригинал, без
поиска. При снятии **глобальной** паузы мониторинга — явный вопрос с длительностью
паузы и кнопками [Да]/[Нет]; «Да» вызывает `userbot.catch_up` по всем активным
источникам. `/export` отдаёт JSON с источниками, ключами, минус-словами и
приёмниками.

## Из брифа, дословно

> «Ввод списком: пришёл текст в 10 строк — добавились 10 ключей, дубли отсеклись.»
> «Минус-слова — отдельный раздел с тем же вводом.»
> «Кнопка «🧪 Проверить»: вставляешь любой текст → бот отвечает «✅ сработало по: ремонт, срочно» / «❌ не сработало» / «⛔ заблокировано минус-словом: вакансия».»
> «Статус: работает ли, сколько чатов, сколько ключей, что в очереди, когда было последнее срабатывание.»
> «Статистика за 7 и 30 дней: сколько сработок, по каким ключам, из каких чатов.»
> «"📊 Топ мусорных ключей" — ключи с наибольшим числом срабатываний, чтобы сразу видеть, что засоряет выдачу.»
> «История: последние 50 срабатываний списком со ссылками. Полнотекстового поиска не нужно.»
> «При снятии паузы бот спрашивает явно: «⏸ Пауза длилась 3 ч 20 мин. Догнать пропущенное? [Да] [Нет]».»
> «Команда /export отдаёт настройки (источники, ключи, минус-слова, приёмники) отдельным JSON — чтобы при переезде на VPS не набивать списки заново.»

## Критерии приёмки

- [ ] Ввод 10 строк добавляет до 10 новых ключей нужного типа; повтор существующего ключа не создаёт дубль
- [ ] Минус-слова добавляются/удаляются в своём разделе тем же вводом
- [ ] «🧪 Проверить» с текстом, содержащим ключ и минус-слово одновременно, отвечает «⛔ заблокировано минус-словом: …»; с текстом без совпадений — «❌ не сработало»; с совпадением без минус-слова — «✅ сработало по: …» с точным списком ключей
- [ ] Экран статуса показывает все перечисленные в брифе пункты одновременно
- [ ] Статистика за 7 и 30 дней даёт разные числа при разном распределении срабатываний по времени (не игнорирует период)
- [ ] «Топ мусорных ключей» отсортирован по убыванию числа срабатываний
- [ ] История показывает не больше 50 записей, каждая — рабочая ссылка на оригинал
- [ ] Снятие глобальной паузы после ≥1 минуты простоя показывает вопрос с длительностью и кнопками [Да]/[Нет]; «Да» запускает догон, «Нет» — нет
- [ ] `/export` возвращает валидный JSON со всеми четырьмя списками
- [ ] ❌ у ключа/минус-слова удаляет без подтверждения
