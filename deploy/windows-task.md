# Автозапуск без Docker: задача Планировщика Windows

Актуально, если вы **не** используете `docker compose up` (см. корневой
`docker-compose.yml` — там автозапуск уже настроен через `restart: unless-stopped`
и делать ничего дополнительно не нужно).

Ниже — как поднять `userbot` и `panel` автоматически при каждом входе в
Windows, без правок кода: используется готовый скрипт `deploy/start-local.ps1`,
который запускает `python -m userbot.main` и `python -m panel.main`.

Перед первым запуском один раз выполните `python configure.py` из корня проекта —
он создаст `.env` и залогинит userbot.

## Вариант А — командой (быстрее всего)

Откройте PowerShell **от имени текущего пользователя** (не администратора —
задача должна запускаться в вашей сессии, чтобы видеть ваш `python`) в корне
проекта и выполните:

```powershell
$repo = (Get-Location).Path
schtasks /create /tn "tg-lead-catcher" /tr "powershell.exe -WindowStyle Hidden -ExecutionPolicy Bypass -File `"$repo\deploy\start-local.ps1`"" /sc onlogon /rl limited /f
```

Проверить, что задача создана:

```powershell
schtasks /query /tn "tg-lead-catcher"
```

Запустить прямо сейчас, не дожидаясь перезапуска:

```powershell
schtasks /run /tn "tg-lead-catcher"
```

Удалить задачу (если понадобится):

```powershell
schtasks /delete /tn "tg-lead-catcher" /f
```

## Вариант Б — через интерфейс «Планировщик заданий»

1. Win+R → `taskschd.msc` → Enter.
2. Справа — «Создать задачу…» (не «Простую задачу», у неё меньше настроек).
3. Вкладка **Общие**: имя `tg-lead-catcher`; «Выполнять только для вошедшего
   пользователя»; галочка «Выполнять с наивысшими правами» — не нужна.
4. Вкладка **Триггеры** → «Создать» → «При входе в систему» → для «Любого
   пользователя» или конкретно вашей учётной записи → ОК.
5. Вкладка **Действия** → «Создать» → «Запуск программы»:
   - Программа: `powershell.exe`
   - Аргументы: `-WindowStyle Hidden -ExecutionPolicy Bypass -File "C:\путь\до\проекта\deploy\start-local.ps1"`
     (подставьте реальный путь к репозиторию)
   - Рабочая папка: `C:\путь\до\проекта`
6. Вкладка **Условия**: снимите «Запускать только при питании от сети», если
   это ноутбук на батарее.
7. ОК, при запросе — введите пароль своей учётной записи Windows.

## Проверка и логи

После запуска (по триггеру или через «Выполнить» в Планировщике) процессы
пишут вывод в `data\logs\userbot.out.log`, `data\logs\userbot.err.log`,
`data\logs\panel.out.log`, `data\logs\panel.err.log` — туда же валятся и
ошибки, если что-то не запустилось.

Остановить вручную: диспетчер задач Windows → найти процессы `python.exe`
(командная строка покажет `userbot.main` / `panel.main`) → «Снять задачу»,
либо `schtasks /end /tn "tg-lead-catcher"` не остановит уже запущенные
дочерние процессы — используйте диспетчер задач.
